# True Life Solution

Premium multi-page Next.js website starter for True Life Solution.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Main routes

- /
- /services
- /services/pest-control
- /services/auto-insurance
- /services/ssdi
- /services/water-damage
- /services/final-expense
- /services/health-insurance
- /about
- /partners
- /contact
- /legal/privacy
- /legal/terms

## Production checklist

- Replace placeholder contact information.
- Connect the contact form to your backend/CRM/email provider.
- Add the real company address and phone number.
- Replace legal placeholders with counsel-reviewed policies.
- Add final logo/favicon and brand assets.
- Review campaign-specific compliance and consent language before launch.
